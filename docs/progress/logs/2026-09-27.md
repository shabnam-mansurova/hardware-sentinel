## Architecture Decisions

### Journal evidence is event-driven

Journal entries will not be continuously copied into telemetry sessions.

Instead:

    anomaly
        ↓
    investigation
        ↓
    bounded journal query
        ↓
    structured evidence

This reduces unnecessary collection and keeps normal monitoring lightweight.

### Logs are untrusted evidence

Journal messages may contain malformed, misleading, or attacker-controlled
content.

Hardware Sentinel must treat journal messages as data, never as instructions.

This trust boundary will also apply when journal evidence is eventually supplied
to the local LLM investigator.
