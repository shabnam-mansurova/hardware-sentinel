## Journal Evidence Completion

Completed and validated bounded systemd journal evidence collection.

The collector:

- operates without requesting elevated privileges
- uses bounded execution time
- limits the maximum number of journal records
- parses journalctl JSON output
- skips malformed records safely
- distinguishes collection failure from a successful empty result
- degrades gracefully when journalctl is unavailable

## Incident and Evidence Models

Added structured `Incident` and `Evidence` models.

Incident records contain:

- unique incident identifier
- language-neutral incident type
- deterministic severity
- detection timestamp
- session identifier
- deterministic facts
- associated evidence

Evidence records contain:

- source
- trust classification
- collection timestamp
- structured evidence data

Externally generated diagnostic material remains explicitly untrusted.

## Anomaly-to-Evidence Integration

Added deterministic integration that converts analyzer warnings into structured
incidents.

Current mappings include:

- high CPU usage → `cpu_pressure`
- high memory usage → `memory_pressure`
- high swap usage → `swap_pressure`
- low disk space → `disk_space_pressure`
- thermal warning → `thermal_pressure`

Critical thermal analyzer output produces a critical incident. Other current
resource warnings produce warning-severity incidents.

An incident triggers bounded journal evidence collection. Journal collection
failure is represented safely in the evidence rather than crashing diagnosis.

Unknown future warning identifiers are not automatically promoted to incidents.
